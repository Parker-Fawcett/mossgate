# Mossgate

A small, ordinary eight-page Next.js site for a fictional neighborhood plant nursery: a home page
and a full catalog page with real, specific, priced inventory, plus six adjacent, similarly-built
pages (about, visit, care guides, events, FAQ, contact) with ordinary static prose.

Built as a purpose-built fixture for
[rebuild-dossier](https://github.com/Parker-Fawcett/rebuild-dossier)'s contract-locking ablation —
specifically to test whether a weak-tier model, mid-rebuild, batch-builds untested-but-adjacent
pages it wasn't asked to build yet, when enforcement is off vs. on. Not a real business.

## Local development

```bash
npm install
npm run dev
```
